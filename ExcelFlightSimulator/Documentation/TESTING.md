The authoritative automatic output is `Tests/results.txt`, generated by Excel executing the packaged VBA. No Python port stands in for native runtime testing. `Tests/assets.json` is a separate build-time geographic/binary check.

## Visual inspection

Inspected actual framebuffer captures, including the v0.2 banked cockpit and focused instrument view. The menu/live-window UI and physical pause/resume checks were performed on v0.1. A fresh v0.2 physical UI check was unavailable because Windows Computer Use returned access denied; native COM-driven tests and framebuffer inspection completed. Runway orientation and slope align with the source imagery. Terrain samples and photographic surface features move with aircraft state. Cockpit text is legible and instrument readings move with flight state. Visible pixelation, simple cloud shapes, simplified chase silhouette, and texture-detail limits remain; they are not concealed as completed photorealistic features.

Corrections made during verification included two VBA compiler issues, runway longitudinal height, native bitmap capture ownership, input taps missed by polling, and status-bar restoration. The final build script fails explicitly if a native test reports FAIL.
